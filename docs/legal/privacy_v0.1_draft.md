## 1. 基本方針

BuildLab（以下「当方」といいます。）は、Webサイト運用管理サービス「SiteOps」（以下「本サービス」といいます。）における個人情報その他の利用者に関する情報を、個人情報の保護に関する法律その他の適用法令に従い適正に取り扱います。

本ポリシーでは、本サービスのアカウント保有者に関する情報（以下「利用者情報」といいます。）と、利用者が自らの業務のために登録する顧客、担当者その他の第三者に関する情報（以下「顧客等第三者情報」といいます。）を区別して記載します。

## 2. 取得する情報

当方は、本サービスの提供に必要な範囲で、次の情報を取得します。

### 2.1 利用者情報

1. アカウント情報：メールアドレス、認証に必要な識別子、メールアドレスの確認状況等
2. 組織情報：利用者が登録する組織名等
3. お問い合わせ情報：お問い合わせの内容、連絡先、対応履歴等
4. 同意履歴：同意した利用規約及びプライバシーポリシーの文書バージョン、同意日時等
5. 技術情報：IPアドレス、ブラウザー・端末に関する情報、アクセス日時、参照元、Cookie又はその他の識別子、認証・エラー・セキュリティに関するログ等のうち、本サービス又は利用する外部サービスにおいて送信・記録されるもの

現時点で決済機能は実装されておらず、当方が本サービスを通じてクレジットカード番号等の決済情報を取得することは想定していません。将来決済機能を導入する場合は、取得情報、処理主体及び利用目的を改めて明示します。

### 2.2 顧客等第三者情報

利用者は、本サービスに次のような第三者に関する情報を登録することがあります。

1. 顧客名、会社名、屋号等
2. 担当者名、メールアドレス、電話番号等の連絡先
3. Webサイト名、URL、CMS種別、稼働状況等
4. ドメイン、サーバー、DNS、SSLその他の管理サービスに関する名称、提供者、管理用ラベル、更新日等
5. 保守契約、タスク、作業履歴及びメモに含まれる情報

本サービスは、Webサイト、サーバー、ドメイン管理サービス等のログインパスワード、APIキー又は認証トークンを保存する機能を提供しません。利用者は、これらの機密情報を入力しないものとします。

## 3. 利用目的

当方は、取得した情報を次の目的のために利用します。

1. 利用者の登録、本人確認、メールアドレス確認、認証及びアカウント管理のため
2. 本サービスの機能を提供し、利用者が登録データを表示、登録、更新又は削除できるようにするため
3. 利用規約及びプライバシーポリシーへの同意履歴を管理するため
4. お問い合わせ、不具合報告その他の依頼に対応するため
5. 本サービスの安定運用、障害対応、不正利用防止、セキュリティ確保及び利用状況の調査のため
6. 本サービスの機能、品質及び操作性を分析・改善するため
7. 利用規約、プライバシーポリシー、サービス内容その他の重要な変更を通知するため
8. 法令上の義務への対応、紛争、権利侵害又は利用規約違反への対応のため
9. 前各号に付随する目的のため

当方が、利用者の行動履歴を分析して個別の広告配信又はプロファイリングを行う場合は、実施前にその取扱いを具体的に明示し、法令上必要な措置を行います。現時点のアクセス解析サービスの導入及び利用方法は未定です。

## 4. 利用者が登録する第三者の情報

1. 顧客等第三者情報は、利用者が自らの業務のために登録する情報です。利用者は、当該情報の取得、本サービスへの登録及び当方への取扱いの委託について、利用目的の特定・通知又は公表、本人の同意その他適用法令上必要な措置を自らの責任で行うものとします。
2. 当方は、顧客等第三者情報を、原則として利用者の指示に従い、本サービスの提供、維持、保守、セキュリティ及びサポートに必要な範囲で取り扱います。
3. 利用者は、顧客等第三者から開示、訂正、削除等の依頼を受けた場合、当方の協力が必要な範囲で当方に連絡するものとします。
4. 当方と利用者の個人情報保護法上の役割、委託先としての契約条件及び利用者の顧客向け通知文の必要性は、正式版公開前に法務レビューの上確定します。

## 5. 外部サービスの利用

当方は、本サービスの提供に当たり、次の外部サービスを利用します。

| 外部サービス | 主な利用目的                                                 |
| ------------ | ------------------------------------------------------------ |
| Supabase     | ユーザー認証、データベースその他本サービスのバックエンド機能 |
| Vercel       | 本サービスのホスティング及び配信                             |

1. これらの外部サービス事業者は、本サービスの提供に必要な範囲で情報を取り扱うことがあります。
2. 各事業者による情報の取扱いには、当方と当該事業者間の契約及び当該事業者のプライバシー関連条件が関係します。
3. データの保存地域、国外での取扱いの有無、委託先の契約上の保護措置及び利用者への追加情報提供の必要性は、本番環境の構成を確定した上で、正式版公開前に確認します。本草案は、Supabase又はVercelのデータ保存地域を特定するものではありません。
4. アクセス解析、エラー監視、決済その他の外部サービスの追加は現時点で未定です。将来追加する場合、本ポリシーの改定その他法令上必要な措置を行います。

## 6. 個人情報の第三者提供

1. 当方は、次の場合を除き、あらかじめ本人の同意を得ることなく個人データを第三者に提供しません。
   1. 法令に基づく場合
   2. 人の生命、身体又は財産の保護のために必要があり、本人の同意を得ることが困難である場合
   3. 公衆衛生の向上又は児童の健全な育成の推進のために特に必要があり、本人の同意を得ることが困難である場合
   4. 国の機関、地方公共団体又はその委託を受けた者が法令の定める事務を遂行することに協力する必要があり、本人の同意を得ることで当該事務の遂行に支障を及ぼすおそれがある場合
   5. その他、適用法令上認められる場合
2. 利用目的の達成に必要な範囲で個人データの取扱いの全部又は一部を委託する場合、事業の承継に伴い個人データが提供される場合その他個人情報保護法上第三者に該当しない場合は、前項の第三者提供に該当しません。
3. 当方が委託を行う場合、当方は、委託する情報の内容及びリスクに応じて委託先を選定し、必要かつ適切な監督を行います。

## 7. Cookie等の利用

1. 本サービスは、ログイン状態の維持、認証、セキュリティ、画面表示、利便性の向上及び本サービスの安定運用のため、Cookie又はこれに類する技術を利用することがあります。
2. 利用者はブラウザーの設定によりCookieを無効にできますが、本サービスのログインその他の機能が利用できなくなることがあります。
3. アクセス解析又は広告目的のCookie等の利用は現時点で未定です。導入する場合、利用するサービス、取得情報、利用目的及び無効化方法を明示します。

## 8. 安全管理措置

1. 当方は、取り扱う情報の性質、量、利用方法及び想定されるリスクに応じて、個人データの漏えい、滅失又は毀損の防止その他の安全管理のために必要かつ適切な措置を講じます。
2. 具体的な措置には、取扱規程・責任体制の整備、アクセス制御、認証、権限管理、通信・保存環境の保護、不正アクセス等の防止、委託先の選定・監督その他合理的な措置が含まれ得ます。
3. 正式版で公表する安全管理措置の内容は、本番環境、運用手順及び委託先との契約を確認し、実際に実施する内容に限定して確定します。本草案は、未確定の措置が既に実施済みであることを表明するものではありません。

## 9. 情報の保存期間

1. 当方は、取得した情報を、利用目的の達成に必要な期間、法令上の義務を履行するために必要な期間、又は紛争・不正利用への対応に合理的に必要な期間保存します。
2. アカウント情報、登録データ、同意履歴、技術ログ、お問い合わせ履歴その他の情報ごとの具体的な保存期間及び削除基準は、法令、運用上の必要性、バックアップの有無及びインフラ仕様を確認した上で、正式版公開前に確定します。
3. アカウントの終了又は削除依頼があった場合でも、法令上の保存義務、紛争対応、不正利用防止その他正当な理由があるときは、必要な範囲で情報を保存することがあります。

## 10. 個人情報の開示・訂正・削除等

1. 利用者その他の本人は、個人情報保護法その他の適用法令に基づき、利用目的の通知、保有個人データ又は第三者提供記録の開示、内容の訂正・追加・削除、利用停止・消去、又は第三者提供の停止を求めることができます。
2. 当方は、請求者の本人確認又は代理権の確認を行った上で、適用法令に従い対応します。法令上応じる義務がない場合又は他の本人の権利利益を害するおそれがある場合等、請求に応じられないことがあります。
3. 顧客等第三者情報に関する請求は、原則として当該情報を登録した利用者が第一の窓口となります。当方は、自らに適用される法的義務及び利用者との関係に応じて必要な協力を行います。
4. 請求方法、本人確認書類、回答方法、対応期間及び手数料の有無は、正式版公開前に確定します。

## 11. 情報漏えい等への対応

1. 当方は、個人データの漏えい、滅失、毀損その他の事故又はそのおそれを認識した場合、事実関係の調査、影響範囲の特定、拡大防止、原因分析及び再発防止等の必要な対応を行います。
2. 当方は、個人情報保護委員会への報告又は本人への通知が法令上必要な場合、適用される要件及び期限に従い対応します。
3. 漏えい等の対応連絡網、判断手順、利用者への連絡方法及び委託先との分担は、β版公開前に運用手順として確定します。

## 12. ポリシー変更

1. 当方は、法令の改正、本サービスの内容、取得する情報、外部サービス又は情報取扱い方法の変更等に応じて、本ポリシーを変更することがあります。
2. 当方は、変更後の内容及び効力発生日を、本サービス上の表示、メールその他適切な方法で周知します。
3. 利用目的を、変更前の利用目的との関連性を有すると合理的に認められる範囲を超えて変更する場合には、本人の同意の取得その他法令上必要な措置を行います。
4. 重要な変更については、必要に応じて再同意を求めます。
